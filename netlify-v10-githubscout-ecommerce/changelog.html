Changelog

Detection ruleset and product changes, dated. The ruleset version shown in each report maps to the entries below.

Ruleset v2.0.0 Engine

Multi-source detection + honest scoring

  • Detection now spans 10 live sources (homepage, product, cart, /products.json, robots, headers, DNS, script-host census, structured data, checkout fingerprint) instead of one HTML string match.
  • Confidence is now corroboration-based (how many independent sources saw the app), capped at 95%.
  • Savings are computed only from detected paid apps; no detections means no estimate.
  • Cost figures relabeled as published-pricing benchmarks with citations; the invalid "PayPal monthly fee" was removed.
  • Spend-tier matching bug fixed so ad-spend bands no longer collapse into higher tiers.
Product Platform

Accounts, entitlements, and a real dashboard

  • Passwordless sign-in; Stripe purchases now provision an account and email a sign-in link.
  • Server-enforced monthly scan quotas; saved scans with before/after comparison and print-to-PDF.
  • Free scans return teaser depth; paid returns the full report with evidence trails.
Security Hardening

Scanner abuse and SSRF fixes

  • DNS-rebinding closed via connect-time address validation; redirects re-validated per hop.
  • Rate limiting keyed on IP only (previously an attacker-supplied field could mint unlimited buckets), with an optional shared store.
  • Non-http(s) URL schemes rejected; magic-link tokens stored hashed.
